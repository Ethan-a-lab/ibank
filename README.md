# ibank · 投资银行学智慧课堂

单文件站点（`index.html`），覆盖第 0 章导论与第 1–7 章，含 20 个真实案例、课程思政、
智能答疑（智谱 GLM + RAG 知识库）、题库与仿真模块。

仓库启用 GitHub Pages 后（**Settings → Pages → Source 选 `main` 分支 / 根目录**）：

| 资源 | 地址 |
|---|---|
| 站点首页 | `https://ethan-a-lab.github.io/ibank/` |

## 配套教材与资料（版权受限，不随站点分发）

站内**不提供任何教材或讲义全文的在线下载**。相关条目在页面上标注为「🔒 校内」，
并给出正版获取渠道：

- **课程主教材**：马晓军《投资银行学：理论与案例》（第 4 版，ISBN 978-7-111-76189-1，
  机械工业出版社）——出版社官方渠道 / 正规图书电商按 ISBN 检索 / 学校图书馆馆藏检索。
- **配套资料**：重点笔记、知识点、名词解释、习题答案——由任课教师整理并随课堂发放。

教师如需课堂在线阅读，把**已获授权**的 PDF 放入站点同目录 `assets/`（此目录已在
`.gitignore` 中排除，不会被提交）。`index.html` 检测到本地文件或校内网段打开时，
条目会自动变为可点击；在线公开访问时保持锁定状态。

## 本地使用

双击 `index.html` 即可，无需服务器。若需阅读本地授权 PDF，`assets/` 需与
`index.html` 同目录。

## 目录结构

```

assets/         本地授权 PDF（不入库，.gitignore 已排除）
```
